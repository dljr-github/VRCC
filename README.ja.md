# VRCC

[English](README.md)、[简体中文](README.zh-Hans.md)、[한국어](README.ko.md) でもお読みいただけます。

マイクに話すと、その言葉が VRChat のチャットボックスにリアルタイム字幕として表示され、その下に最大 3 言語の翻訳が並びます。すべてお使いの Windows 10 または 11 の PC の中で動きます。クラウドサービスも API キーもありません。

```
You say:   "Hello, how are you today?"
Chatbox:   Hello, how are you today?
           こんにちは 今日はどうですか?
```

VRCC はプラグアンドプレイを目指して作られています。起動すると初回セットアップウィザードがマシンの性能を調べ、モデルを選び、パフォーマンスモードまで決めてくれます。どの推奨も当てずっぽうではなく、実測したベンチマークまでさかのぼれます。細かい調整つまみは設定にそのまま残っていますが、触る必要はないはずです。

## VRCC を動かす

かかる時間は 5 分ほど、それに一度だけのモデルのダウンロードが加わります。Python を入れる必要も、API キーを探す必要もありません。すべて Windows 10 または 11 のローカルで動きます。

<a id="download"></a>

1. リリースページを開きます。すぐ動くプログラムは、最初にたどり着くリポジトリのページには置かれていません。置いてあるのは
   [Releases](https://github.com/dljr-github/VRCC/releases/latest) の中です。このリンクから最新版に直接行けます。
   開くとバージョン番号、リリースノート、そしてページの下のほうに **Assets** という見出しの一覧があります。ファイルはその中にあります。

   Assets の最後の 2 つ、"Source code (zip)" と "Source code (tar.gz)" は、プログラムではなく VRCC のソースコードです。どちらも使いません。選ぶのは `VRCC-cuda-windows-x64` と `VRCC-windows-x64` の 2 つで、それぞれ後ろにバージョン番号が付いています。

2. 自分の PC に合うほうの zip を取ります。`VRCC-cuda-windows-x64` は CUDA 版で、VRAM 8 GB 以上、ドライバー 570 以降の NVIDIA グラフィックスカード向けです。字幕はカード側で処理され、ほぼ即座に出ます。`VRCC-windows-x64` は CPU 版です。ダウンロードはずっと小さく、VRAM 8 GB 未満の NVIDIA カード、AMD や Intel のグラフィックス、グラフィックスカードがまったく無い PC ではこちらを取ります。字幕の中身は同じで、ほんの少し遅いだけです。標準のモデルは CPU でも追いつく大きさに選んであります。

   自分の環境を確かめるには、Ctrl+Shift+Esc で タスク マネージャー（Task Manager）を開き、**パフォーマンス**（Performance）タブの **GPU** をクリックします。カードの名前、専用メモリ、ドライバーのバージョンがすべてそのページにあります。調べるのが面倒なら CUDA 版の zip を取ってください。ダウンロードは大きくなりますが、使えるカードが見つからなければ自分でプロセッサ側に切り替えて動きます。

   GPU アクセラレーションは今のところ NVIDIA カードだけです。手元に AMD のハードウェアがなく、テストできないからです。

3. zip のブロックを解除してから展開します。ダウンロードしたファイルを右クリックし、メニューの一番下にある **プロパティ**（Properties）を選びます。「全般」（General）タブの下のほうに **許可する**（Unblock）のチェックボックスがあれば、チェックを入れて OK をクリックします。Windows はインターネットから来たファイルに印を付けます。ここでその印を消しておくと、次の手順の警告も出なくなります。

   次に zip をもう一度右クリックして **すべて展開**（Extract All）を選びます。エクスプローラーは zip をフォルダーのように見せますが、その中からプログラムを起動すると、Windows には zip の中身のファイルが 1 つ渡るだけなので動きません。ドキュメントなど適当な場所を選ぶと、`VRCC.exe` が入った VRCC フォルダーができます。そのフォルダーはまとめたまま、好きな場所に置いてください。インストール作業はありません。

4. `VRCC.exe` を実行します。今展開したフォルダーの中でダブルクリックします。「Windows によって PC が保護されました」（Windows protected your PC）という青い画面が出ることがあります。メッセージの下の小さなリンク **詳細情報**（More info）をクリックし、現れた **実行**（Run anyway）ボタンを押します。VRCC はコード署名されていないので、Windows があまり見かけていないプログラムにはこの表示が出ます。上のリリースページから取ったファイルならクリックして進める価値がありますが、どこでも同じように進めてよいという話ではありません。さきほど 許可する にチェックを入れていれば、そもそも出ないこともあります。

5. 初回セットアップウィザードにモデルをダウンロードさせます。VRCC を初めて起動すると、ウィザードがマシンを調べて音声認識モデルと翻訳モデルを選び（取得するのは約 1 GB から 3 GB）、ダウンロードします。始まる前に実行デバイスやモデルを変更することもできます。これは一度きりです。何をどう選ぶかの表は [初回起動](#first-run) にあります。

6. VRChat で OSC を有効にします。**Action menu → Options → OSC → Enabled** を開きます。VRCC は OSC で VRChat に字幕を送ります（既定のアドレスは `127.0.0.1:9000`）。これがないと字幕はチャットボックスに届きません。

7. マイクと言語を選びます。VRCC で **マイク**、**話す言語**（自分が話す言語）、そして翻訳先の **言語を最大 3 つ** 選びます。

8. 話し始めます。あなたの言葉が VRChat のチャットボックスにリアルタイム字幕として表示され、その下に翻訳が付きます。ウィンドウ下部の入力欄に文字を打って、同じように送ることもできます。

あとから **設定** を開けば、表示言語を変えたり、モデルを入れ替えたり、速度モードと品質モードを切り替えたりできます。普段の使い方の残りは [使い方](#usage)、字幕がまったく出ないときにまず見るのは [困ったときは](#troubleshooting) です。ソースからのビルドは開発に参加したい人向けです（[DEVELOPING.md](DEVELOPING.md) を参照）。

<a id="what-runs-on-your-machine"></a>

## お使いのマシンで動くもの

あなたの声が PC の外に出ることはありません。VRCC の裏にクラウドサービスはなく、貼り付ける API キーもありません。

音声認識は [faster-whisper](https://github.com/SYSTRAN/faster-whisper)、ヨーロッパ言語向けの NVIDIA [Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3)（[onnx-asr](https://github.com/istupakov/onnx-asr) 経由で ONNX 版として実行）、または中国語・日本語・韓国語・英語向けの [SenseVoice-Small](https://huggingface.co/FunAudioLLM/SenseVoiceSmall) で動きます。SenseVoice は使えますが推奨はしていません。機械翻訳は [CTranslate2](https://github.com/OpenNMT/CTranslate2) で動き、NLLB、M2M100、MADLAD のモデルを使います。ウィザードがこの中からあなたの代わりに選びます。その選択の裏にある実測値は [モデルの選び方](#picking-a-model) にあります。

<a id="first-run"></a>

## 初回起動

設定されたモデルがまだダウンロードされていない場合は、初回セットアップウィザードが開き、あなたのハードウェアと話す言語（Windows の表示言語から取ります）に合わせてモデルを選び、ダウンロードします。

| お使いのマシン | 音声認識 | 翻訳 | ダウンロード |
| ------------ | -------------- | ----------- | -------- |
| VRAM 16 GB 以上の NVIDIA GPU | `large-v3-turbo` | `nllb-1.3B-int8` | 約 3 GB |
| VRAM 11 GB から 16 GB の NVIDIA GPU | `large-v3-turbo` | `nllb-600M-int8` | 約 2.3 GB |
| GPU なし、または VRAM 11 GB 未満の NVIDIA GPU で、Parakeet が対応する言語 | `parakeet-tdt-0.6b-v3` | `nllb-600M-int8` | 約 1.3 GB |
| GPU なし、または VRAM 11 GB 未満の NVIDIA GPU で、それ以外の言語 | whisper `small` | `nllb-600M-int8` | 約 1.1 GB |

VRChat 自体がカードのビデオメモリをたくさん使います。VRCC はそのために 8 GB を空けておき、翻訳モデルの分を差し引いた残りに合わせて音声モデルの大きさを決めます。`large-v3-turbo` に 8 GB ではなく約 11 GB を求めるのはこのためです。それ未満だと、隣で動く VRChat に余裕が残りません。

日本語・韓国語・中国語も、ほかの言語と同じモデルを使います。Parakeet はこれらに対応していないので、GPU の無いマシンや VRAM 11 GB 未満の NVIDIA GPU では、Parakeet ではなく whisper `small` を選びます。`sense-voice-small` もモデルウィンドウから選べて、サイズもずっと小さい（240 MB）のですが、実際の VRChat の発話ではテストで faster-whisper のほうが正確に書き起こしたため、もう推奨していません。

ウィザードは選んだ内容を表示し、ダウンロード前に実行デバイスを変更させてくれます。

![NVIDIA GPU 向けにモデルを推奨している初回セットアップウィザード](assets/images/firstrun.png)

ほかの選択肢は whisper `tiny`（約 75 MB）から `large-v3`（約 3 GB）まで、それに NVIDIA の `parakeet-tdt-0.6b-v3`（約 690 MB、非常に正確で高速）があり、これは英語 + ヨーロッパの 24 言語に限られます（日本語・韓国語・中国語は非対応）。翻訳モデルは `m2m100-418M-int8`（約 480 MB）から `madlad400-3b`（約 3.5 GB）まであります。実測した字幕の品質では NLLB が推奨の先頭に立ちます。M2M100 のモデルは寛容なライセンスの代替です（[モデルのライセンス](#model-licenses) を参照）。モデルはあとから **モデル** ダイアログで追加・削除できます。実測した精度と速度は下の [モデルの選び方](#picking-a-model) を見てください。

VRCC が動く準備を終えると、メインウィンドウの横にセットアップの手順パネルが開きます。項目には、字幕をオンにする、音声モデルの読み込みが終わる、あなたの声が VRCC に届く、VRChat がネットワーク上に現れる、字幕が OSC で送り出される、が並び、さらにスピーカーから拾った音の項目が任意で付きますが、これがほかの項目を止めることはありません。VRChat の項目が示すのは、その OSC サービスが mDNS で自分を公開したことだけで、何かがゲームに届いたことではありません。そのため mDNS を遮断するネットワークでは、VRChat が問題なく動いていてもこの項目にチェックが付かないままになり、その間はパネルが起動のたびに開き続けます。字幕の項目は逆向きの証拠です。字幕が送られたことは示しますが、VRChat が受け取ったことは示しません。OSC にはメッセージが届いたかを確かめる仕組みがないからです。また、VRChat への送信をオフにすると、この項目はパネルが求める条件から外れます。パネルが求める項目がすべて通れば、次からの起動では開かなくなります。その前に閉じた場合はそのセッションの間だけ消え、次の起動でまた出てきます。パネル自身の「今後表示しない」ボタンを使えば、項目が通っているかどうかにかかわらず、代わりにこれを完全に止められます。どちらの方法で閉じても、設定の「基本」ページから、いつでも呼び戻せます。

<a id="usage"></a>

## 使い方

1. VRChat を起動して OSC を有効にします。**Action menu → Options → OSC → Enabled**。
2. VRCC を起動します。マイク、話す言語、翻訳先の言語を最大 3 つ選びます。
3. 話します。まずマイクから定常的な背景ノイズが取り除かれ（既定でオン）、次に発話が自動で区切られ（Silero VAD）、書き起こされ、翻訳され、チャットボックスに送られます。送信は VRChat のチャットボックスのレート制限に収まるよう間隔が調整されるので、話し続けてもゲーム内のスパムミュートには引っかかりません。弱めたりオフにしたりするには **設定 → 音声認識 → 背景ノイズを低減する** を使います。
4. **相手の話を読む:** メインウィンドウの**相手の音声**（Hear others）を押すと、スピーカーから出ている声を書き起こして翻訳するので、自分が読めない言語で話している人の話を追えます。聞き取り対象と表示する言語は**設定 → 基本 → 相手の発言**（What other people say）で選びます。知っておくことが 2 つあります。1 つは、Windows にアプリごとの音声を取り出す仕組みがないため、VRChat の音声チャンネルではなく出力デバイス全体を取り込むことです。ゲーム音やワールドの音も書き起こされます。もう 1 つは、これが VRCC のウィンドウの中だけに表示されることです。ほかの人の言葉がチャットボックスに送られることはありません。その場の全員がすでに聞いていますし、中継すれば他人の発言をあなたの名前で公開し直すことになるからです。グラフィックスカードが無い場合は、自分の字幕と 1 つの音声モデルを共有するので、どちらも遅くなります。
5. **入力したメッセージ:** メインウィンドウ下部のテキスト入力欄は、打った文字を同じ 翻訳 → チャットボックス の経路で送ります（声を出したくないときに便利です）。
6. **ミュート連動:** 有効にすると、VRChat で自分をミュートしたときに VRCC が聞き取りを完全にやめます（無視する、逆にする、も設定できます）。ミュート中の発話は取り込まれないので、文の途中でミュートを解除した場合、字幕になるのは解除より後に話した分だけです。これは VRChat の OSCQuery による検出を使うため、**VRChat が同じ PC で動いているときだけ** 働きます（localhost）。字幕そのものはどちらでも動きます。

![日本語とスペイン語の翻訳を付けて字幕を表示しているメインウィンドウ](assets/images/main-window.png)

<a id="interface-language"></a>

### 表示言語

インターフェースは既定で Windows の表示言語に従い、18 言語を話せます（English, 日本語, 한국어, 简体中文, 繁體中文, Español, Français, Deutsch, Italiano, Português (Brasil), Русский, Українська, Polski, Nederlands, Türkçe, Bahasa Indonesia, Tiếng Việt, ไทย）。別の言語にするには **設定 → 基本 → VRCC の表示言語**（Language）で選びます。設定ウィンドウを閉じるとすぐ反映されます。これが変えるのは VRCC 自身のインターフェースだけです。字幕の言語はメインウィンドウで選びます。

<a id="performance-modes"></a>

### パフォーマンスモード

**設定 → 基本 → モード** で 2 つのプリセットを切り替えます。

- **速度**（既定）: 貪欲デコード（ビーム 1）で、無音が 600 ms 続いたら字幕を確定します。字幕がいちばん速く出ます。
- **品質**: ビーム 5 で、800 ms 待ちます。言い回しが目に見えて良くなり、字幕 1 つあたり約 200 ms 遅くなります。

モードが変えるのは字幕だけです。翻訳は **設定 → 翻訳 → 詳細（微調整）** にある独自の探索幅を保ちます。これらのプリセットの根拠になった実測は音声認識についてのもので、翻訳については何も言っていないからです。

モードを切り替えると、詳細ページの無音の待ち時間と、音声認識ページの探索幅が書き換わります。それらを自分で設定していた場合、VRCC はどの値かを挙げて先に確認します。2 つのモードを行き来して比べるだけなら確認は出ません。その値はあなたではなくプリセットから来たものだからです。

Parakeet と SenseVoice は常に最高精度でデコードするので、どちらかが有効な音声モデルの間はモードの操作が灰色になります。個々のつまみ（VAD のタイミング、ビームサイズ、品質のしきい値など）は **設定 → 詳細** にあります。

<a id="picking-a-model"></a>

## モデルの選び方

この節の数値はすべて `tools/bench_stt.py` から出ています。[LibriSpeech](https://www.openslr.org/12/) test-clean の 100 発話を、アプリが使うのと同じエンジンの経路で、1 台のマシン（Windows 11、Ryzen 9 9950X3D、RTX 5090、ドライバー 610.62）で実行した結果です。WER は英語の朗読音声に対する単語誤り率、レイテンシは 1 発話を書き起こすまでの時間の中央値です。精度の数値と相対的な速度比はほかのマシンにも当てはまりますが、絶対的なレイテンシは当てはまりません。遅い CPU では、ここにある CPU 時間がどれもだいたい同じ倍率で伸びると考えてください。完全な表と方法は
[DEVELOPING.md](DEVELOPING.md#speech-to-text-benchmarks) に、ほかのハードウェアでの数値は
[benchmarks/RESULTS.md](benchmarks/RESULTS.md) にまとめてあります。

NVIDIA GPU なら、既定の `large-v3-turbo` のままにしてください。WER 1.7% で `large-v3` と並びながら約 3.5 倍速く、どの言語にも対応します。

CPU では、話す言語によります。

- ヨーロッパの 25 言語のどれか: `parakeet-tdt-0.6b-v3` を使ってください。0.13 s で 2.3% に届き、既定の `small`（0.74 s で 3.7%）を精度 *と* レイテンシの両方で上回ります。しかも僅差ではありません。その言語群の中なら、話されている言語を自分で判別もします。
- 日本語、韓国語、中国語、またはその言語群の外にあるもの: `small` のままにしてください。これを上回る whisper のモデルはどれも、CPU では字幕 1 つに数秒かかります。

Parakeet は GPU より CPU のほうが速く（0.13 s 対 0.21 s）、int8 の ONNX グラフが CUDA に向いていないためです。ですから CPU 版で十分ですし、同じ PC で VRChat を遊ぶなら GPU をまるごとゲームに残せます。デバイスを自動のままにしておけば、VRCC がこれをやってくれます。

distil 系のモデルは、この計測では GPU で `large-v3-turbo` に、CPU で Parakeet と `small` に負けたので、選ぶ理由はほとんどありません。

初回セットアップウィザードは、あなたのハードウェアと、Windows の表示言語から取った話す言語に合わせて選びます。CPU では、Parakeet が対応する言語を話すなら Parakeet、そうでなければ `small` になります。話す言語を自動にすると whisper のモデルのままになります。事前に言語が分からない状態では、ヨーロッパ言語だけのモデルで足りるとは信頼できないからです。

<a id="where-things-are-stored"></a>

## 保存される場所

| 内容 | 既定の場所 |
| ---- | ---------------- |
| 設定 | `%LOCALAPPDATA%\VRCC\VRCC\config.json` |
| モデル | `%LOCALAPPDATA%\VRCC\VRCC\models\` |
| ログ | `%LOCALAPPDATA%\VRCC\VRCC\logs\vrcc-<date>-<time>.log` |

実行のたびにデバッグ詳細つきのログファイルが 1 つ書かれ、新しいものから 5 つが残ります。問題を報告するときは、そのフォルダーにある最新のファイルを添付してください。

`--portable` を付けて実行すると、設定・モデル・ログをアプリケーション自身のフォルダーに置きます（USB メモリや、環境を分けたインストールに便利です）。

<a id="updating"></a>

## アップデート

VRCC は起動時に新しいリリースがないか確認し、見つかると知らせを出します。知らせにはリリースページをブラウザーで開くボタンが付いています。何かを自動でダウンロードしたり入れ替えたりはしないので、更新の手順は初回と同じです。新しい zip を取り、ブロックを解除し、展開して、新しいフォルダーの `VRCC.exe` を実行します。

設定とダウンロード済みのモデルはアプリケーションのフォルダーに置かれていないので（上の表を参照）、そのまま引き継がれます。モデルが 2 回ダウンロードされることはなく、初回セットアップウィザードも出てきません。古いフォルダーは納得できるまで残しておき、そのあとで削除できます。

知らせが要らなければ、**設定** を開いて **詳細 / 上級者向け** のページに行き、**新しいバージョンが利用可能になったら知らせる** のチェックを外します。

ポータブル版は話が逆です。`--portable` では設定・モデル・ログがすべてアプリケーション自身のフォルダーにあるので、そのフォルダーを置き換えると失われます。先に `config.json` と `models` フォルダーを新しいほうにコピーするか、新しいビルドを古いフォルダーの上から展開してください。

<a id="model-licenses"></a>

## モデルのライセンス

このリポジトリの **コード** と、そこからダウンロードされる **モデル** は別物です。モデルのライセンスが自分の使い方に合うか確認してください。

- **NLLB** モデル（既定の `nllb-600M-int8`、ほかに 1.3B と 3.3B）: **CC-BY-NC-4.0**、*非商用利用のみ*。これらが推奨モデルなので、VRCC を商用で使う場合（有料配信や案件配信、仕事での利用）は、**モデル** ウィンドウで M2M100 のモデルを選んでください。
- **M2M100** モデル（`m2m100-418M-int8`、ほかに 1.2B）: **MIT** なので、そうした制限はありません。VRChat でありそうな 60 の発話を日本語・中国語・韓国語に訳したブラインド比較では、NLLB 600M より精度が低いという結果でした。それが寛容なライセンスとの引き換えです。
- **MADLAD-400**（`madlad400-3b`）: **Apache-2.0**。
- Whisper モデル: **MIT**（OpenAI の重み、SYSTRAN による CT2 変換）。
- **Parakeet**（`parakeet-tdt-0.6b-v3`）: **CC-BY-4.0**（NVIDIA の重み、istupakov による ONNX 版）。
- **GTCRN**（*背景ノイズを低減する* のノイズ除去。ダウンロードではなく同梱）: **MIT**（Xiaobin Rong, <https://github.com/Xiaobin-Rong/gtcrn>）。

<a id="troubleshooting"></a>

## 困ったときは

- **「GPU が見つかりません」/ すべてが CPU で動く**: CUDA 版（`VRCC-cuda-windows-x64` の zip、またはソースから `pip install -e .[cuda]` で入れたもの）を実行していること、NVIDIA ドライバーが 570 以上であることを確かめてください。GPU アクセラレーションは今のところ NVIDIA のみです（テストできる AMD のハードウェアがありません）。それ以外で CPU だけで動くのは正常です。字幕の中身は同じで、ほんの少し遅いだけです。標準のモデルは CPU でも追いつく大きさになっています。
- **GPU の VRAM が足りなくなる**: エンジンはそのセッションの間、自動で CPU（int8）に切り替わります（字幕は同じ、レイテンシは増えます）。GPU のままにしたいときは小さいモデルを選んでください。
- **VRChat に字幕が出ない**: VRChat で OSC を有効にし（Action menu → Options → OSC）、VRCC の設定にある OSC のアドレスが VRChat の待ち受け先と合っているか確認してください（既定は `127.0.0.1:9000`）。ほかの OSC ツール（OSCRepeater のようなルーターなど）を使っている場合は、VRCC をそのルーターのポートに向けてください。
- **ミュート連動が何もしない**: これには VRChat が *同じマシン* で動いていること（localhost の mDNS / OSCQuery による検出）、ゲーム内で OSC が有効なこと、アバターが `MuteSelf` を報告することが必要です。
- **VRCC の起動時に小さい画面が出る**: これは VRCC が何を読み込んでいるかを示すもので、表示できるものが用意できると閉じます。アップデート後や再起動後の最初の起動は遅くなります。Windows がそのプログラムのファイルを初めてディスクから読むからです。起動に失敗した場合は、最新のログファイルにどこまで進んだかが残るので、報告のときに役立ちます。
- **最初の書き起こしが遅い**: モデルの読み込みとウォームアップは、起動画面が閉じたあともウィンドウの中で続いています。そのあとは全速で字幕が流れます。
- **バグの報告**: 上のログフォルダーにある最新のファイルを添付してください。実行ごとにデバッグ詳細つきのファイルが 1 つ書かれ、新しいものから 5 つが残るので、タイムスタンプがいちばん新しいファイルが、問題の起きた実行です。
- **VRCC をもう一度起動しても何も起きない**: 同時に動くのは 1 つだけで、もう一度起動すると、動いているほうに姿を見せるよう伝えます。それでも出てこないときは、Windows が最後にクリックしたものにフォーカスを渡したままかもしれないので、タスクバーのボタンを見てください。
- **セットアップの手順が出てこない**: パネルを閉じるとそのセッションの間は消え、求められている項目が済んでいなければ次の起動でまた開きます。パネル自身の **今後表示しない** ボタンを使えば、代わりにそれきり出てこなくなります。どちらの場合も、**設定 → 基本** を開いて **セットアップの手順をもう一度表示** を使えば呼び戻せます。
